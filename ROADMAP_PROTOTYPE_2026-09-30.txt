============================================================
1. CO ZNACZY „PROTOTYP GOTOWY”
============================================================

To nie jest jeszcze wersja produkcyjna. To jest działająca wersja, z której
może skorzystać nowy użytkownik bez ręcznej edycji bazy i bez obchodzenia UI.

Obowiązkowy przepływ:

REGISTER -> LOGIN -> HOME -> ARCHIVE -> GAME PAGE -> PLAY
-> WYBÓR EMULATORA -> ADD TO LIBRARY -> LIBRARY -> PROFILE
-> UPLOAD GAME -> EDIT GAME -> PLAY OWN GAME -> FRIEND -> CHAT

Prototyp jest DONE dopiero, gdy ten przepływ działa:
- na świeżej bazie,
- na świeżych kontach,
- na desktopie,
- na telefonie,
- z prawidłowym 401/403 dla operacji prywatnych,
- bez błędów builda.

Poza zakresem Prototype:
- grupy i rozbudowane funkcje chatu,
- rozbudowane powiadomienia,
- zaawansowana moderacja i system odznak,
- produkcyjne skalowanie i pełny audyt bezpieczeństwa,
- nowe funkcje po rozpoczęciu freeze.
